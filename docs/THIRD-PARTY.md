## Source code of the GPL and LGPL components

The complete corresponding source code of the binaries in
`paguro-node-installer` – CRIU at tag `v4.2.1` plus Paguro's patches, and the
Ubuntu 24.04 source packages of every library and program in its
`/opt/paguro` bundle – is published as a separate image built from the same
Dockerfile (`make installer-sources`):

```
<registry>/paguro-node-installer-sources:<same tag as the installer>
```

It contains the sources under `/sources/` (no executable content). The
Alpine and Debian base-image packages are unmodified distribution packages;
their sources are available from Alpine Linux (aports, the packages'
upstream URLs) and Debian (source packages of the same versions).

**Written offer:** for three years after we distribute a given Paguro image,
we provide the complete corresponding source code of any GPL- or
LGPL-licensed component in it, on a physical medium or for download, for no
more than the cost of performing this distribution. Ask the Paguro
maintainers (see the project's repository).
