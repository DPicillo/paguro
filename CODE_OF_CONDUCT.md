# Code of conduct

Paguro follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
in all of the project's spaces – issues, pull requests, discussions, reviews
– and wherever someone represents the project.

In short: be kind and precise. Criticise code and measurements, not people.
Harassment, insults, personal or political attacks and publishing someone
else's private information are not accepted.

## Reporting

Report unacceptable behaviour privately to the maintainer, David Picillo
([github.com/DPicillo](https://github.com/DPicillo)), through the
repository's private reporting form
([Security → Report a vulnerability](https://github.com/DPicillo/paguro/security/advisories/new);
start the title with "Conduct:"), not in a public issue. Reports are
treated confidentially. The maintainer decides on the consequences along
the Covenant's enforcement guidelines: a correction, a warning, a
temporary ban or a permanent ban.

Security vulnerabilities are not conduct reports: see
[SECURITY.md](SECURITY.md).
